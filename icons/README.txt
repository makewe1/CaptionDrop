CaptionDrop icon — flow

Original vector artwork for this project: one solid graphite shape derived from
taichi's continuous curve, on a transparent background. The icon has no enclosing
badge, border, dots, or interior details. One foreground color keeps it simple.

Source: icon.svg
Extension sizes: icon-16.png, icon-32.png, icon-48.png, icon-128.png
Large preview: icon-512.png

Render the PNGs from the SVG with:
  node scripts/generate-icons.mjs

The in-player button uses the exact same silhouette in the player's current
control color, so the mark remains monochrome and readable over the video.
